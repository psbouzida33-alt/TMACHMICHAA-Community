# TMACHMICHAA Community

Landing page for the [TMACHMICHAA Discord community](https://discord.gg/T2e8VFT7Fm) — 230+ members, game roles, voice rooms, house rules, and server life at a glance.

Single self-contained `index.html` (fonts and styling inlined, no build step). To host it with GitHub Pages: **Settings → Pages → Deploy from branch → `main` / `/ (root)`**.
